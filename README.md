## 실행 환경과 설치

Python 3.10 이상과 Git만 있으면 됩니다. 표준 라이브러리만 쓰므로 따로 설치할 패키지는 없습니다.

```bash
git clone https://github.com/no-people/py_KKMOYS.git
cd py_KKMOYS
python -m moim --help      # macOS에서 python 이 없으면 python3
```

## 설정 파일

처음 한 번 예제 설정을 복사합니다. 기존 `config.json`이 있다면 복사하지 말고 내용을 확인하세요.

```powershell
Copy-Item config.example.json config.json
```

설정은 UTF-8 JSON 파일입니다. 예제의 금액은 원 단위 정수입니다.

| 항목 | 의미 | 예 |
|---|---|---|
| `group` | 모임 이름 | `"AI 동아리"` |
| `data` | 명부·지출·회비 등을 저장할 자료 파일 | `"data.json"` |
| `members_file` | 참여자 명부 파일 | `"members.txt"` |
| `rules` | 분류 규칙 파일 | `"rules.json"` |
| `backup_dir` / `log_dir` | 백업 / 로그 폴더 | `"backup"` / `"logs"` |
| `treasurer` | 은행 출금을 지출로 기록할 때의 총무 이름 | `"김민수"` |
| `budget.monthly` | 월 전체 예산 | `1500000` |
| `budget.by_category` | 분류 이름별 월 예산 | `{"식비": 800000, "장소": 300000}` |
| `dues.monthly` | 1인당 월 회비 | `20000` |
| `warn_ratio` | 예산 사전 경보 기준 비율 | `0.8` |

명령은 지금 폴더의 `config.json`을 읽습니다. 다른 설정 파일을 쓸 때만 명령 묶음 앞에 `--config`를 붙입니다.
예: `python -m moim --config 연습.json budget --help`.
`data`, `members_file`, `rules`, `backup_dir`, `log_dir`의 상대 경로는 설정 파일이 있는 폴더를 기준으로 해석합니다.
로그 기록·자동 복구 안내 등 통합 연결은 각 담당 작업이 병합된 뒤 사용할 수 있습니다.
예산을 바꾸려면 `config.json`의 `budget` 안에 있는 `monthly` 값을 수정합니다.

## 분류 규칙 (`cat`)

`cat`은 지출 메모의 키워드 등으로 분류를 정합니다. 규칙을 추가한 뒤 미리 보고 적용합니다.
설정 파일의 `rules` 항목에 규칙 파일 경로가 필요합니다(예제: `"rules": "rules.json"`).
`add`와 `remove`는 규칙 파일만 저장하고, `apply`는 바뀐 지출이 있을 때 자료 파일을 저장합니다.

### 규칙 추가: `add`

<!-- 함수: add_rule -->

메모에 `저녁` 또는 `점심`이 있으면 식비로 분류하는 규칙을 만듭니다.
규칙 추가만으로 기존 지출의 분류가 바뀌지는 않습니다.

**명령 사용**

```powershell
python -m moim cat add 식비 --keywords 저녁 점심
```

**출력 예**

```text
규칙 추가: 0. 식비  키워드: 저녁, 점심  우선순위: 0
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- `add`의 선택 인자는 `--priority 숫자`(큰 값 우선, 같으면 먼저 등록한 규칙),
  `--payer 이름`(낸 사람), `--min 원`·`--max 원`(금액 범위, 양 끝 포함)입니다.
- 키워드·낸 사람·금액 범위 중 조건을 하나 이상 지정해야 합니다.

### 규칙 목록: `list`

<!-- 함수: load_rules -->

규칙 파일(JSON)에 저장된 분류 규칙을 번호와 함께 보여 줍니다.

**명령 사용**

```powershell

```

**출력 예**


## 정산 (`settle`)

모임 지출을 사람별로 나눠 누가 얼마를 받고 보내야 하는지 계산합니다.

### 잔액 확인: `balance`

<!-- 함수: balances, balance_sum -->

기간 동안 사람마다 낸 돈, 부담할 돈, 보낸·받은 송금, 잔액을 보여 주고 잔액 합계가 0인지 검사합니다.
잔액이 양수면 받을 돈, 음수면 보낼 돈입니다. 자료 파일은 바꾸지 않습니다.

잔액 = 낸 돈 − 부담 + 보낸 송금 − 받은 송금

**명령 사용**

```powershell
python -m moim settle balance --month 2026-11
python -m moim settle balance --start 2026-10-01 --end 2026-11-30
```

**출력 예** (`--month 2026-11`)

```text
이름    낸 돈   부담    보낸 송금  받은 송금  잔액
------  ------  ------  ---------  ---------  ------
김민수  36,000  17,000          0      5,000  14,000
이서연       0  14,500      5,000          0  -9,500
박지훈  10,000  14,500          0          0  -4,500
잔액 합계: 0
```

**출력 예** — 기간에 자료가 없을 때 (`--month 2026-10`)

```text
이 기간에 정산할 지출·송금이 없습니다
```

**오류 예**

| 입력 | 출력 |
|---|---|
| `python -m moim settle balance` | `오류: 기간을 지정하십시오(--month YYYY-MM 또는 --start, --end)` |
| `python -m moim settle balance --month 2026-13` | `오류: 달 형식이 잘못되었습니다(YYYY-MM): 2026-13` |
| `python -m moim settle balance --start 2026-11-31 --end 2026-12-01` | `오류: 날짜가 잘못되었습니다(YYYY-MM-DD, 실제 있는 날짜): 2026-11-31` |
| `python -m moim settle balance --start 2026-11-20 --end 2026-11-10` | `오류: 기간이 잘못되었습니다(시작일이 끝일보다 늦음): 2026-11-20 ~ 2026-11-10` |

**참고**

- 기간은 시작일과 끝일을 모두 포함합니다. `--month`는 그달 1일~말일입니다.
- 삭제 표시된 지출은 계산에서 빠집니다.
- 나머지 1원은 낸 사람부터, 그다음 참여자 목록 순서로 줍니다. 비율이 있는 지출은 비율대로 나눕니다.
- 표의 순서는 명부 순서입니다. 기간 안에 낸 돈·부담·송금이 있는 사람만 나옵니다.
- 잔액 합계가 0이 아니면 `잔액 합계: N (경고: 0이 아닙니다. 자료를 확인하십시오)`가 나옵니다. 자료 파일을 확인하세요.

## 예산·회비 (`budget`)

월 예산 대비 지출과 남은 금액, 회비 입금, 모임 통장 잔고를 관리합니다.

### 월 예산과 남은 금액: `status`

<!-- 함수: month_status -->

월 예산은 설정 파일의 `budget.monthly`에서 읽습니다. 지출은 그달 1일부터 말일까지 세고,
삭제 표시한 지출은 제외합니다. 예산과 사용액이 같으면 초과가 아닙니다.

**명령 사용**

```powershell
python -m moim budget status --month 2026-11
```

**출력 예**

```text
2026-11 월 예산: 1,500,000원
사용액: 0원
남은 금액: 1,500,000원
예산 이내
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 특정 날짜까지의 사용액만 보려면 `--today 2026-11-15`를 덧붙입니다.

### 회비 입금 기록: `pay`

<!-- 함수: record_payment -->

`--member`에는 명부에 있는 이름을 씁니다. 금액의 쉼표와 `원` 표시는 허용되며,
소수점은 사사오입해 원 단위로 저장합니다. 0원 이하 입금은 받지 않습니다.

**명령 사용**

```powershell
python -m moim budget pay --date 2026-11-02 --member "이서연" --amount "20,000" --memo "11월 회비"
```

**출력 예**

```text
회비 입금 기록: 2026-11-02 이서연 20,000원
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- `pay`는 자료 파일에 새 입금 한 건을 저장합니다. 같은 명령을 다시 실행하면 별도 입금이 추가되므로,
  이미 기록한 입금을 다시 입력하지 않도록 확인하세요. 조회 명령은 자료 파일을 변경하지 않습니다.

### 통장 잔고: `balance`

<!-- 함수: treasury_balance -->

잔고는 기록한 회비 입금 합계에서 삭제되지 않은 지출 합계를 뺀 금액입니다.

**명령 사용**

```powershell
python -m moim budget balance
```

**출력 예**

```text
통장 잔고: 20,000원
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 특정 날짜까지 보려면 `--until YYYY-MM-DD`를 덧붙입니다. 지정한 날짜 당일도 포함합니다.

### 분류별 예산과 경보: `categories`

<!-- 함수: category_status -->

분류별 예산과 그달 분류별 사용액을 비교하고, 초과하거나 예산의 80%를 넘으면 경보를 표시합니다.

**명령 사용**

```powershell
python -m moim budget categories --month 2026-11
```

**출력 예**

```text
식비: 예산 50,000원, 사용 30,000원, 잔액 20,000원 (이내)
교통: 예산 10,000원, 사용 15,000원, 잔액 -5,000원 (초과)
미분류: 예산 0원, 사용 500원, 잔액 -500원 (초과)
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 기본 경보 비율은 80%입니다. 정확히 80%일 때는 경보가 없고, 이를 초과하면 `주의`로 표시합니다.
- 월 전체 사용액에 대한 경보는 `budget status`에서도 확인합니다.
- 예산이 없는 분류의 지출도 빠지지 않게 표시하며, 그 분류의 예산은 0원으로 봅니다.

### 월말 지출 예측: `forecast`

<!-- 함수: forecast -->

예측은 월 1일부터 기준일 당일까지의 지출을 지난 날짜 수로 나눈 뒤 그달 일수를 곱합니다.
기준일은 선택한 달 안에 있어야 하며, 결과는 사사오입한 원 단위 정수입니다.

**명령 사용**

```powershell
python -m moim budget forecast --month 2026-11 --today 2026-11-15
```

**출력 예**

```text
2026-11 월말 예상 지출: 61,000원 (기준일: 2026-11-15)
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 미래 지출과 삭제 표시는 제외합니다.

### 예산 대비 실제 지출 표: `table`

<!-- 함수: budget_table -->

분류마다 예산, 실제 지출, 차이를 표로 보여 줍니다. 마지막 줄은 전체입니다.

**명령 사용**

```powershell
python -m moim budget table --month 2026-11
```

**출력 예**

```text
분류    예산     실제    차이
------  -------  ------  ------
식비     50,000  30,000  20,000
교통     10,000  15,000  -5,000
미분류        0     500    -500
------  -------  ------  ------
전체    100,000  45,500  54,500
전체 예산은 월 전체 예산 설정 기준입니다.
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 차이는 `예산 - 실제`이므로 음수는 초과 지출입니다.
- 전체 행의 예산은 분류별 예산 합계가 아니라 설정된 월 전체 예산입니다.

### 월별 회비 미납자: `unpaid`

<!-- 함수: unpaid -->

그달 1일 또는 말일에 회원인 사람이 대상입니다. 가입일과 탈퇴일 당일도 회원으로 봅니다.
월 회비가 20,000원이고 김민수·이서연·박지훈 모두 대상 회원이며 그달 입금이 없다면:

**명령 사용**

```powershell
python -m moim budget unpaid --month 2026-11
```

**출력 예**

```text
김민수: 납부 0원, 미납 20,000원
이서연: 납부 0원, 미납 20,000원
박지훈: 납부 0원, 미납 20,000원
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 분할 입금은 합산하며, 이미 월 회비 이상 낸 사람은 표시하지 않습니다.

### 은행 거래내역 가져오기: `import-bank`

<!-- 함수: import_bank -->

**CSV 읽기 공통 함수(기능 6)가 병합된 뒤 사용할 수 있습니다.**
현재 main에서는 아직 실행되지 않으며, 아래는 해당 기능이 준비된 후의 사용 예와 예상 출력입니다.

파일 형식은 [은행 거래내역 형식](docs/은행거래내역형식.md)을 따릅니다.
설정의 `treasurer`가 총무 이름이며, `--treasurer`로 이번 명령의 총무를 지정할 수도 있습니다.
예제 파일의 입금 1건과 출금 1건을 처음 가져오는 경우:

**명령 사용**

```powershell
python -m moim budget import-bank bank.csv
```

**출력 예**

```text
은행 가져오기: 지출 1건, 회비 입금 1건
```

**오류 예**

| 입력 | 출력 |
|---|---|
| | |

**참고**

- 중복 거래는 건너뛰고 행 번호를 안내합니다. 잘못된 행은 이유와 행 번호를 보여 주며 나머지는 가져옵니다.
- 출금은 그날 회원 전원을 참여자로 기록하고, 확정 기간에 속한 출금은 거부합니다.
- 가져오기는 자료를 변경하므로 파일과 총무 이름을 확인한 뒤 실행하세요.

## 연습 자료와 검사

실제 자료와 섞이지 않도록 연습 자료는 별도 폴더에 만드세요.
출력 위치와 옵션을 먼저 확인합니다.
아래는 Windows의 `python` 기준입니다. macOS에서 `python` 명령이 없으면 `python3`로 바꿔 실행하세요.

```bash
# 연습 자료 만들기의 옵션 보기
python tools/gen_data.py --help
# practice 폴더에 2026년 11월 연습 자료 만들기
python tools/gen_data.py practice --month 2026-11
```

```bash
# 1) 모든 파이썬 파일에 문법 오류가 없는지 검사 (아무것도 안 나오면 통과)
python -m compileall -q moim tools
# 2) 기능 파일끼리 서로 import 하지 않는지 검사
python tools/check_imports.py
# 3) tests 폴더의 테스트 전부 실행 (마지막 줄이 OK 면 통과)
python -m unittest discover -s tests
```

검사 세 가지는 GitHub의 자동 검사(`check`)와 같습니다. 병합 요청을 올리기 전에 직접 실행해 보세요.

검사 결과의 `OK`는 실행한 테스트가 통과했다는 뜻입니다.
`skipped`는 아직 구현되지 않은 기능 등에 대한 건너뜀이며, 모든 기능의 완성을 뜻하지 않습니다.
실패하면 `FAIL`·`ERROR` 아래에 표시된 테스트 이름과 오류 내용을 확인하세요.
개인 설정·자료 파일과 `backup/`, `logs/`는 저장소에 올리지 않습니다.
